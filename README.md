# Дауыс беру DApp

№6 практикалық жұмыс — React, Web3.js және MetaMask арқылы
жергілікті Ganache блокчейнімен жұмыс істейтін дауыс беру қосымшасы.

Кандидаттар келісімшарттан оқылады. Әр әмиян мекенжайы осы
келісімшартта тек бір рет дауыс бере алады.

## Мүмкіндіктер

- MetaMask арқылы шотты қосу.
- Ganache желісіне ауысу.
- Шот пен желі өзгерістерін өңдеу.
- Кандидаттардың толық тізімін келісімшарттан оқу.
- Кандидаттардың дауыс санын көрсету.
- Транзакция арқылы дауыс беру.
- Бір кандидаттың немесе барлық кандидаттардың дауыстарын жаңарту.
- Транзакцияның жіберілу, сәтті аяқталу және қате күйлерін көрсету.
- Қайталанған дауыс беруді келісімшарт деңгейінде бұғаттау.
- Мобильді құрылғыларға бейімделген қазақша интерфейс.

## Орнату

Дайын жоба каталогында тәуелділіктерді орнатыңыз:

```bash
npm install
```

Егер жобаны нөлден жасасаңыз, алдымен React үлгісін құрыңыз:

```bash
npm create vite@latest voting-dapp-react -- --template react
cd voting-dapp-react
```

Содан кейін жоба файлдарын көшіріңіз. Берілген `package.json`
файлын пайдаланыңыз: онда React 18 нұсқасы көрсетілген.

Қажетті қосымша пакеттерді орнату командалары:

```bash
npm install web3
npm install tailwindcss @tailwindcss/vite
```

## Ganache желісін іске қосу

Пайдаланатын нұсқаңызға сәйкес команданың бірін жеке терминалда
орындаңыз.

### Ganache CLI 6

```bash
ganache-cli --port 8545 --chainId 1337 --networkId 1337
```

### Ganache 7

```bash
npx ganache --server.port 8545 --chain.chainId 1337 --chain.networkId 1337 --chain.hardfork london
```

Қосымша жұмыс істеп тұрған кезде Ganache процесі де жұмыс істеп
тұруы керек.

## MetaMask желісін баптау

MetaMask ішінде жергілікті желіні мына параметрлермен қосыңыз:

| Параметр | Мәні |
|---|---|
| Желі атауы | Ganache жергілікті желісі |
| RPC мекенжайы | `http://127.0.0.1:8545` |
| Chain ID | `1337` |
| Валюта белгісі | `ETH` |

Ganache терминалында көрсетілген қаражаты бар сынақ шотын
MetaMask-қа импорттаңыз.

Қосымша `window.ethereum` провайдерін пайдаланады. Сондықтан
React қолданатын нақты RPC мекенжайы MetaMask-тағы белсенді
желінің параметрлерімен анықталады.

Егер бұрын `7545` портымен желі қосылған болса, оның белсенді
RPC мекенжайын `http://127.0.0.1:8545` етіп жаңартыңыз.

## Келісімшартты Remix арқылы орналастыру

1. [Remix IDE](https://app.remix.live/) ашып, `Voting.sol` файлын
   жасаңыз және келісімшарт кодын енгізіңіз.
2. Құрастырушы нұсқасын `0.8.19`, ал қосымша параметрлердегі
   EVM нұсқасын `london` етіп таңдап, келісімшартты құрастырыңыз.
3. Орналастыру бөлімінде `Browser Extension` ортасын таңдаңыз.
   Ескі интерфейсте бұл орта `Injected Provider - MetaMask`
   деп аталуы мүмкін. MetaMask-та Ganache желісін таңдаңыз.
4. Конструкторға кандидаттардың атауларын енгізіп, орналастыру
   транзакциясын MetaMask-та растаңыз.
5. Орналастырылған келісімшарттың мекенжайын көшіріп, `.env`
   файлына енгізіңіз.

Конструктор аргументінің мысалы:

```json
["Айша", "Данияр", "Меруерт"]
```

Орналастыру кезіндегі ETH жіберу мәнін `0` етіп қалдырыңыз.

`Remix VM` — браузер ішіндегі бөлек блокчейн. Ganache желісінде
жұмыс істеу үшін орналастыруды Ganache-ке қосылған MetaMask
арқылы орындаңыз.

## .env файлын баптау

Жобаның түбірінде, `package.json` жанында `.env` файлын жасаңыз:

```dotenv
# Remix-та орналастырылған келісімшарттың нақты мекенжайы.
VITE_VOTING_ADDRESS=0xYourDeployedContractAddress
```

`0xYourDeployedContractAddress` орнына Remix берген нақты
келісімшарт мекенжайын енгізіңіз.

`src/contracts/Voting.js` мекенжайды мына анықтама арқылы оқиды:

```js
export const VOTING_ADDRESS = (
  import.meta.env.VITE_VOTING_ADDRESS ?? ''
).trim();
```

Әр жаңа орналастырудан кейін алынған мекенжайды `.env` ішінде
өзіңіз жаңартыңыз. Remix бұл файлды автоматты түрде өзгертпейді.

`.env` файлы өзгергеннен кейін Vite серверін қайта іске қосыңыз.
Құрастырылған нұсқа үшін `npm run build` командасын қайта орындаңыз.

## Қосымшаны іске қосу

Жоба каталогында орындаңыз:

```bash
npm run dev
```

Браузерде терминалда көрсетілген мекенжайды ашыңыз.
Әдетте ол `http://localhost:5173` болады.

Қосымшаны құрастыру:

```bash
npm run build
```

Құрастырылған нұсқаны жергілікті тексеру:

```bash
npm run preview
```

## Қолдану тәртібі

1. Ganache желісін іске қосыңыз.
2. React қосымшасын браузерде ашыңыз.
3. «MetaMask-ты қосу» батырмасын басыңыз.
4. Қажет болса, «Ganache-ке ауысу» батырмасын басыңыз.
5. Кандидаттың «Дауыс беру» батырмасын басыңыз.
6. Транзакцияны MetaMask-та растаңыз.
7. Сәтті тіркелген дауыс пен жаңартылған дауыс санын тексеріңіз.

Бір кандидаттың дауыс санын жаңарту үшін оның карточкасындағы
`↻` батырмасын пайдаланыңыз.

Барлық нәтижені қайта оқу үшін «Барлық дауыстарды жаңарту»
батырмасын басыңыз.

## Бір мекенжай — бір дауыс ережесі

Келісімшарт дауыс берген мекенжайларды сақтайды:

```solidity
mapping(address => bool) public hasVoted;
```

Алғашқы сәтті дауыс кезінде `hasVoted[msg.sender]` мәні `true`
болады. Осы мекенжайдан сол кандидатқа немесе басқа кандидатқа
қайта дауыс беру қабылданбайды.

Ереже React арқылы да, Remix арқылы да орындалады. Бетті қайта
жүктеу дауыс беру құқығын қалпына келтірмейді.

Шектеу осы орналастырылған келісімшарттағы мекенжайға қолданылады.
Бір адамның бірнеше мекенжай қолдануын анықтау үшін бөлек
қатысушыларды тексеру механизмі қажет.

## Келісімшарт интерфейсі

| Әдіс немесе оқиға | Мақсаты |
|---|---|
| `constructor(string[] candidateNames)` | Кандидаттардың бастапқы тізімін қабылдау |
| `getCandidates()` | Кандидаттардың толық тізімін оқу |
| `candidatesCount()` | Кандидаттар санын оқу |
| `candidateList(uint256)` | Бір кандидаттың атауын оқу |
| `totalVotesFor(uint256)` | Кандидаттың дауыс санын оқу |
| `votesReceived(uint256)` | Сақталған дауыс санын оқу |
| `hasVoted(address)` | Мекенжайдың бұрын дауыс бергенін тексеру |
| `voteForCandidate(uint256)` | Бір кандидатқа дауыс беру |
| `VoteCast` | Кандидат нөмірін, дауыс берушіні және жаңа дауыс санын жариялау |

Кандидат нөмірлері нөлден басталады. Үш кандидат болса,
жарамды нөмірлер — `0`, `1`, `2`.

Кандидаттардың атаулары орналастыру кезінде анықталады.
React оларды `getCandidates()` арқылы оқиды.

## Ganache қайта іске қосылғанда

Егер Ganache жаңа блокчейн күйімен іске қосылса, бұрынғы
келісімшарт пен оның дауыс деректері сол жаңа күйде болмайды.

Мұндай жағдайда:

1. Келісімшартты Remix арқылы қайта орналастырыңыз.
2. Алынған мекенжайды `.env` файлына енгізіңіз.
3. Vite серверін қайта іске қосыңыз.
4. Браузер бетін қайта жүктеңіз.

Жаңа келісімшартта дауыс сандары нөлден басталады және
`hasVoted` белгілері қайтадан бастапқы күйде болады.

### Блокчейн күйін сақтау

Қайта іске қосқанда бұрынғы келісімшарт пен дауыстарды сақтау
үшін Ganache дерекқорын пайдаланыңыз.

Ganache CLI 6 үшін:

```bash
ganache-cli --port 8545 --chainId 1337 --networkId 1337 --deterministic --db ./ganache-data-v6
```

Ganache 7 үшін:

```bash
npx ganache --server.port 8545 --chain.chainId 1337 --chain.networkId 1337 --chain.hardfork london --wallet.deterministic --database.dbPath ./ganache-data-v7
```

Әр іске қосқанда сол нұсқаны, дерекқор жолын және шот параметрлерін
пайдаланыңыз.

Дерекқор параметрін алғаш рет қосқанда жаңа дерекқор құрылады.
Бұрын тек жедел жадта болған блокчейн оған автоматты түрде көшірілмейді.

Детерминделген шот параметрі бірдей сынақ шоттарын береді.
Келісімшарт пен дауыс күйін дерекқор параметрі сақтайды.

| Тексеру | Күтілетін нәтиже |
|---|---|

| Бірінші дауыс | Таңдалған кандидаттың дауыс саны біреуге артады |
| Сол мекенжаймен қайта дауыс беру | Қайта дауыс беруге болмайтыны туралы хабар көрсетіледі |
| Сол мекенжаймен басқа кандидатқа дауыс беру | Әрекет қабылданбайды |
| Басқа мекенжаймен дауыс беру | Алғашқы дауыс қабылданады |
| MetaMask сұрауынан бас тарту | Дауыс саны мен `hasVoted` мәні өзгермейді |

| Бетті қайта жүктеу | Сол келісімшарттағы дауыс беру шектеуі сақталады |

## Жиі кездесетін қателер

| Қате | Себебі | Шешімі |
|---|---|---|
| Келісімшарт мекенжайы туралы қате | `.env` мәні бос немесе үлгі мекенжайы қалған | `VITE_VOTING_ADDRESS` мәніне нақты мекенжай енгізіп, Vite серверін қайта іске қосыңыз |
| Бұл мекенжайда келісімшарт жоқ | Басқа желі, басқа RPC немесе ескірген мекенжай қолданылған | MetaMask-та `8545` RPC мекенжайын және `.env` ішіндегі мекенжайды тексеріңіз |
| `hasVoted is not a function` | Құрылған келісімшарт нысанының ABI құрамында әдіс жоқ | Жаңа келісімшарттың толық ABI сипаттамасын қолданып, қосымшаны қайта іске қосыңыз |
| ABI сәйкессіздігі | ABI мен орналастырылған келісімшарт нұсқалары әртүрлі | Remix-та құрастырылған соңғы нұсқаның ABI және мекенжайын пайдаланыңыз |
| `invalid opcode` | Байткодтың EVM нұсқасы ортаға сәйкес емес | Solidity `0.8.19`, EVM `london` арқылы құрастырып, қайта орналастырыңыз |
| `nonce too high` | Ganache күйі өзгерген, MetaMask ескі транзакция нөмірлерін сақтаған | Ganache сынақ шотының әрекеттері мен nonce деректерін тазалап, қайта қосылыңыз |
| ETH жеткіліксіз | Шотта газ төлеміне сынақ ETH жоқ | Ganache ішіндегі қаражаты бар сынақ шотын пайдаланыңыз |
| `EADDRINUSE` | `8545` портын басқа процесс пайдаланып тұр | Осы порттағы Ganache процестерін тексеріп, біреуін пайдаланыңыз |

Келісімшартқа `hasVoted` қосқаннан кейін жаңа нұсқаны блокчейнге
орналастыру қажет. React ішіндегі ABI жаңарту блокчейндегі
бұрынғы келісімшарттың кодын өзгертпейді.
